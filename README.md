# flash-cards

Personal, offline flashcard app for Android. Learning project for Kotlin +
Jetpack Compose, Room, Hilt, and Navigation Compose.  
Claude Code was used on the development of this project.

## Stack
Kotlin, Jetpack Compose, Navigation Compose, Room (KSP), Hilt, Material 3,
kotlinx.serialization, JUnit.
